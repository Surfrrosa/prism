# Audit Log: 2026-06-09

Foundational audit pass against The Pragmatic Programmer principles
plus a11y on the extension UI, security review of the MV3 manifest,
and dep vuln scan. PR: `audit/2026-06-09` → main.

## Shipped in this PR

**Orthogonality (`/coupling`):**
- Verdict: codebase is exemplary. The 4 `src/lib/` modules
  (`sources`, `storage`, `score`, `types`) are documented canonical
  singletons in CLAUDE.md.
- Three-layer architecture (background / popup+sidepanel / lib).
  No content script — prism is privacy-first and never reads page
  content (only domain matches via `tabs.onUpdated`).
- Zero cycles, zero wildcards, zero cross-layer violations.

**DRY (`/drift`):**
- No model IDs, no year-bound constants, no hardcoded URLs in source.
- Em-dash usage is zero.
- The `show(id)` helper is duplicated between popup and sidepanel —
  already documented in CLAUDE.md as intentional ("extract to
  `src/lib/dom.ts` if a third site needs it"). At N=2, leave it.

**Broken windows (`/zombie`):**
- Zero commented-out code, zero TODOs/FIXMEs/HACKs, zero empty
  catches.

**Accessibility (`/a11y`) on extension UI:**
- Added `<title>` to `popup/index.html` ("Prism") and
  `sidepanel/index.html` ("Prism — Media diet dashboard"). Both
  previously had none — screen readers announced "Untitled" when
  the popup or side panel opened.
- Replaced `<div id="app">` with `<main id="app">` in both files,
  giving screen readers a landmark to jump to. `id="app"` preserved
  so JS selectors continue to resolve.

**Security review (`/security-review`) on the manifest:**
- Permissions audit: `tabs`, `storage`, `alarms`, `notifications`,
  `sidePanel` — all justified by code paths that use them.
- **Zero `host_permissions`.** Prism never requests access to page
  content. It only uses `tabs.onUpdated` to read the URL on
  navigation, then matches against the local MBFC database. This is
  a meaningful privacy posture and worth calling out.
- No `eval`, no `new Function`, no untrusted innerHTML.

**Dependency vulnerability (`/vuln`):**
- `npm audit` clean. Zero vulnerabilities.

## Light verifications

- `npx tsc --noEmit` clean.
- `npm run build` clean (`dist/` regenerates correctly).

## Out of scope (declined / not needed)

- Extracting `show(id)` to `src/lib/dom.ts`. At N=2, explicitly
  documented in CLAUDE.md as a controlled duplication.
- `<title>` on `docs/index.html` / `docs/privacy.html` — already
  have titles.

## Onlooker takeaway

A privacy-first MV3 extension with zero host permissions, a 4-module
shared lib, and a clean dependency tree. The audit's most visible
change is the popup and side panel announcing themselves properly to
screen readers.
